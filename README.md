**Modeling and Optimization**

This repository contains implementations of optimization problems from the INF170 – Modeling and Optimization course.

The models are implemented in Python using the Gurobi Optimizer.

**Problems Implemented**

**Traveling Salesman Problem (TSP)**
Three different formulations are implemented:

MTZ formulation

Svestka formulation

Dantzig–Fulkerson–Johnson (DFJ) formulation

Pickup and Delivery Problem (PDP)

Exact mathematical model with routing, capacity, and time constraints.

**Structure**
TSP_Assignment1/      # Traveling Salesman Problem models
PDP_Assignment2/      # Pickup and Delivery Problem model
Main_report.R         # Analysis and report

Python

Gurobi Optimizer
